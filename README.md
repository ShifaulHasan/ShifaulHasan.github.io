## 🚀 Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/ShifaulHasan/ShifaulHasan.github.io.git
   ```
2. Open the folder
   ```bash
   cd ShifaulHasan.github.io
   ```
3. Open `index.html` in your browser (or use the VS Code **Live Server** extension).

## ☁️ Deployment

This site is deployed with **GitHub Pages**. Any change pushed to the `main` branch is published automatically at `https://shifaulhasan.github.io` (it may take a minute or two to update).
