Projects

Skin lesion classification

Bachelor's thesis · Python, TensorFlow/Keras, EfficientNet

Seven-class classifier trained on 10,015 dermoscopic images. Combines EfficientNet backbones with triplet attention and fuses model layers using MCC-weighted and Cohen's Kappa averaging. Grad-CAM shows which part of the lesion drives each prediction.
